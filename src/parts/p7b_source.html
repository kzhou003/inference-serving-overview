16源码导读：带着问题读代码

文中所有源码链接都固定在某个 commit（与本文写作时 GitHub 上的 main 一致），行为与链接不会因为上游重构而失效；想看最新版本，在 GitHub 页面按 y 切换或手动换成 main。◈ Code Wiki 链接指向 Google Code Wiki 为该仓库生成的结构化讲解（按模块解释架构和调用关系），适合在读源码前先建立全局图；若某个仓库还没生成，页面会提示。

怎么读最高效
  • 先在 Code Wiki 上看模块划分，再按下面的“精读顺序”从入口一路跟到 kernel，每个文件只回答表里那一个问题。
  • 用最小的模型（如 0.5B–1B）本地起服务，在 scheduler 的主循环和 model runner 的前向入口打断点，发一个请求，看一步里数据结构怎么变。
  • 配合 PyTorch profiler / Nsight Systems 看一个 decode step 的时间线，把源码里的函数和时间线上的 kernel 对应起来。
